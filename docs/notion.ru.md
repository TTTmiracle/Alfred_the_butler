# 🔗 Подключение Notion (MCP)

[O'zbekcha](notion.md) · **Русский**

Через MCP ваш помощник читает страницы в Notion, создаёт новые, заполняет таблицы.
Например: *«Запиши в Notion сегодняшние расходы»*, *«Что в таблице проектов просрочено?»*

**Важно:** он видит только те страницы, к которым вы дали доступ. Не весь Notion.

---

## 1. Создайте интеграцию

1. [notion.so/profile/integrations](https://www.notion.so/profile/integrations) → **New integration**
2. Название: `Jarvis` (или имя вашего помощника), тип: **Internal**
3. **Capabilities** (что может делать):
   - ✅ Read content
   - ✅ Update content
   - ✅ Insert content
   - ❌ User information — не нужно

   > Если нужно только чтение — оставьте только **Read content**. Это самый безопасный вариант.

## 2. Скопируйте ключ

На странице интеграции: **Internal Integration Secret** → **Show** → скопируйте. Он начинается с `ntn_`.

Этот ключ — как пароль. Никому не давайте, не отправляйте в чаты.

## 3. Дайте доступ к странице

Создайте в Notion страницу, например **«Jarvis»**. Помощник будет работать только с ней и её вложенными
страницами.

Два способа:
- в настройках интеграции: **Access** → **Edit access** → выберите страницу
- или на самой странице: **⋯** (справа вверху) → **Connections** → выберите интеграцию

> 💡 Вложенные страницы подключаются автоматически. Поэтому создайте одну страницу «Jarvis» и кладите
> всё внутрь — остальные ваши страницы останутся закрытыми.

## 4. Подключите на сервере

```bash
cd Alfred_the_butler
git pull
bash notion.sh
```

Спросит ключ → проверит → подключит → научит помощника правилам работы с Notion.

## 5. Попробуйте

В Telegram:
- *Какие у меня страницы в Notion?*
- *Создай в Notion страницу «Список покупок»: хлеб, молоко, яйца*

- *Добавляй в утренний отчёт задачи из Notion* — помощник сам запишет это в `AGENTS.md`

## Полезные команды

```bash
openclaw mcp list            # подключённые MCP-серверы
openclaw mcp probe           # работает ли, сколько инструментов
openclaw mcp unset notion    # отключить Notion
```

Сменить ключ: снова запустите `bash notion.sh`.

## Безопасность

- Давайте интеграции только нужные права (шаг 1). Нужно только чтение — только Read.
- Подключайте только одну страницу (шаг 3) — финансы и личное пусть останутся закрытыми.
- На странице Notion может быть текст «сделай это» — помощник не должен выполнять его как команду
  (prompt injection). `notion.sh` записывает это правило в порядок работы.
- Ключ хранится на сервере в `~/.openclaw/openclaw.json`. Надёжно храните пароль от сервера.

## Другой путь: официальный Remote Notion MCP

У Notion есть свой сервер: `https://mcp.notion.com/mcp`. Вместо ключа — вход через браузер (OAuth).
Notion рекомендует его, но нужен браузер — на VPS без экрана неудобно. Поэтому этот репозиторий использует
сервер с ключом. Если вы на своём компьютере:

```bash
openclaw mcp add notion --url https://mcp.notion.com/mcp --transport streamable-http --auth oauth
openclaw mcp login notion
```
