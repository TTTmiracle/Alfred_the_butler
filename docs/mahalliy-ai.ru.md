# 🏠 Локальный AI — «Jarvis-станция»

[O'zbekcha](mahalliy-ai.md) · **Русский**

«Jarvis + Mac Studio» из Instagram и YouTube — это именно оно: AI-модель работает не на сервере компании в
интернете, а **в коробке у вас на столе**.

## Зачем на это тратятся

| Плюс | Комментарий |
|---|---|
| 🔒 Данные не уходят | ничего не отправляется в OpenAI/Google. Для клиник, банков, юристов — обязательное условие (урок 15) |
| ♾️ Без ограничений | нет оплаты за каждый запрос. Пусть Jarvis работает круглосуточно — счёта не будет |
| 🌐 Работает без интернета | после загрузки модели |
| 🤖 Много агентов | несколько Jarvis в одной коробке (по одному на клиента) |

| Минус | Комментарий |
|---|---|
| 💸 Начальная цена | от $1 300 до $10 000+ |
| 🧠 Качество | лучшие локальные модели всё ещё уступают лучшим облачным (Claude, GPT) |
| 🐢 Скорость | медленнее облака |
| 🔧 Всё на вас | отключили свет или интернет — Jarvis тоже выключился |

**Расчёт:** если на API уходит $50 в месяц, коробка за $2 700 окупится примерно за 4,5 года. Только ради
экономии — не стоит. Ради приватности, безлимита или требований клиента — стоит.

## Главное правило: память (RAM)

Модель должна целиком помещаться в память. **Файл модели + ~30% ≤ память** (урок 15).

В Mac и AMD Ryzen AI Max процессор и видеокарта используют **одну общую память** (unified memory) — поэтому
маленькая коробка со 128 GB тянет большие модели. В обычном компьютере ограничивает память видеокарты
(VRAM, обычно 8–24 GB).

**Скорость** ≈ скорость памяти (GB/s) ÷ размер модели (GB). Поэтому быстрая память Mac Studio важна.

**Для агента нужна модель минимум ~9B.** Маленькие модели (2–4B) годятся для чата, но в работе агента —
запуск команд, чтение файлов — часто ошибаются. Хороший результат начинается с 27B.

## Две схемы

**А) Всё в одной коробке** — проще всего

```
Telegram ⇄ [ Mac Studio: OpenClaw + Ollama ]
```

**Б) Раздельно** — надёжнее

```
Telegram ⇄ [ дешёвый VPS: OpenClaw ] ⇄ (Tailscale) ⇄ [ коробка дома: Ollama ]
```

Jarvis всегда включён на VPS, тяжёлую работу (модель) делает домашняя коробка. Они связаны через
[Tailscale](https://tailscale.com) — закрытую частную сеть; Ollama не открывается в интернет.

## Установка (вариант А, Mac или Linux)

**1. Ollama** — [ollama.com/download](https://ollama.com/download)

**2. Скачать модель** (по объёму памяти):

```bash
ollama pull qwen3.5:27b      # для 64 GB
# ollama pull qwen3.5:9b     # для 16–32 GB
```

**3. Увеличить контекст** — агенту нужно минимум 64 000 токенов:

```bash
# Linux (systemd):
sudo systemctl edit ollama
#   [Service]
#   Environment="OLLAMA_CONTEXT_LENGTH=65536"
sudo systemctl restart ollama

# Mac: в настройках приложения Ollama поставьте «Context length» на 64k
```

**4. Jarvis:**

```bash
git clone https://github.com/TTTmiracle/jarvis.git
cd jarvis
bash setup.sh        # на вопрос «Qaysi AI» → 6 (Ollama)
```

**5. Чтобы работало постоянно:**
- Mac: *Настройки → Энергосбережение → «Не переходить в режим сна при выключенном дисплее»*
- **ИБП** (источник бесперебойного питания) — чтобы Jarvis не выключался при отключении света
- Проводной интернет (не Wi-Fi)

⚠️ В OpenClaw адрес Ollama должен быть **без `/v1`**: `http://127.0.0.1:11434`. С `/v1` агент перестаёт
нормально вызывать команды (документация OpenClaw).
