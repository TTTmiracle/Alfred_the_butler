# 🤖 Jarvis — ваш личный AI-помощник

[O'zbekcha](README.md) · **Русский**

Личный AI-помощник, который живёт в Telegram и работает на вашем сервере. Он:

- общается с вами в Telegram (на узбекском или русском)
- записывает ваши задачи и напоминает о них
- каждое утро в 08:00 сам присылает отчёт: погода, задачи, что было вчера
- выполняет работу на сервере — но перед неразрешённой командой спрашивает вас в Telegram
- отвечает только вам — если пишут другие, молчит

Внутри работает [OpenClaw](https://openclaw.ai) — самый популярный open-source AI-агент 2026 года. Этот
репозиторий превращает его в Jarvis и настраивает безопасно.

## Что нужно

| | Что | Где взять |
|---|---|---|
| 1 | **Сервер** (VPS) — Linux, минимум 2 GB RAM | Contabo, HOSTIN.UZ, AIRNET и т.д. (~60 000 сум/мес). Или свой компьютер — [локальный вариант](docs/mahalliy-ai.ru.md) |
| 2 | **Токен Telegram-бота** | в Telegram: [@BotFather](https://t.me/BotFather) → `/newbot` |
| 3 | **Ваш Telegram ID** | напишите `/start` боту [@userinfobot](https://t.me/userinfobot) |
| 4 | **Ключ AI** (API key) — один из списка | ниже ⬇️ |

### Какой AI выбрать

| Провайдер | Комментарий |
|---|---|
| **DeepSeek** | дешёвый, хорош для старта |
| **Google Gemini** | есть бесплатный лимит — чтобы попробовать |
| **OpenAI** (ChatGPT) | сильный, средняя цена |
| **OpenRouter** | один ключ — много моделей, есть и бесплатные |
| **Anthropic** (Claude) | один из самых умных, дороже. Setup ставит более дешёвый Sonnet |
| **Ollama** | локальная модель — бесплатно, данные никуда не уходят, но нужен мощный компьютер → [подробнее](docs/mahalliy-ai.ru.md) |

⚠️ При создании ключа поставьте **лимит расходов** (например, $5 в месяц). Бесплатные модели слабее в работе
агента, а некоторые используют ваши данные для обучения — для работы с клиентами берите платный ключ.

## Установка

Зайдите на сервер:

```bash
ssh root@IP_СЕРВЕРА
```

Скачайте репозиторий и запустите установку:

```bash
git clone https://github.com/TTTmiracle/jarvis.git
cd jarvis
bash setup.sh
```

`setup.sh` спросит: токен бота → Telegram ID → какой AI → API-ключ. Остальное сделает сам:

1. Проверит сервер (`check.sh`) — есть ли связь с Telegram, интернет, RAM
2. Установит OpenClaw
3. Подключит выбранный AI
4. Поставит характер Jarvis (на узбекском) и безопасные настройки
5. Включит утренний отчёт (08:00 по Ташкенту)

Когда закончит — напишите боту в Telegram: **Salom Jarvis** 👋

> Файлы характера на узбекском, но Jarvis отвечает на том языке, на котором вы пишете. Хотите всё на
> русском — просто скажите ему: *«Отвечай всегда по-русски, запиши это в USER.md»*.

## Как настроить Jarvis под себя

Кто такой Jarvis, задают обычные текстовые файлы. Они на сервере: `~/.openclaw/workspace/`

| Файл | Что | Пример |
|---|---|---|
| `SOUL.md` | характер, стиль, границы | «Ты помощник администратора моего ресторана» |
| `USER.md` | информация о вас | имя, профессия, какие ответы вам нравятся |
| `AGENTS.md` | порядок работы, состав утреннего отчёта | «Добавляй в отчёт вчерашние заказы» |
| `vazifalar.md` | список задач | Jarvis ведёт его сам |

Редактировать:

```bash
nano ~/.openclaw/workspace/SOUL.md
```

Или просто скажите в Telegram: *«С этого момента отвечай короче, запиши это в USER.md»*.

**Идеи:**
- 🍔 Ресторан: «Каждый день в 23:00 присылай итоги продаж за день»
- 👩‍🏫 Учитель: «Утром напоминай план уроков на сегодня»
- 💼 Фрилансер: «Каждый понедельник составляй список задач на неделю»

## Полезные команды

```bash
openclaw status                  # всё ли работает
openclaw logs --follow           # смотреть, что делает Jarvis, в реальном времени
openclaw cron list               # запланированные задачи
openclaw cron run <ID>           # запустить утренний отчёт прямо сейчас
openclaw gateway usage-cost      # сколько потрачено
openclaw security audit          # проверка безопасности
openclaw gateway restart         # перезапуск
openclaw gateway stop            # выключить
```

Новая задача по расписанию (например, каждую пятницу в 18:00):

```bash
openclaw cron add --name juma --cron "0 18 * * 5" --tz Asia/Tashkent \
  --message "Подготовь итоги недели" --announce --channel telegram --to <TELEGRAM_ID>
```

## Безопасность — что настроено

| Настройка | Что делает |
|---|---|
| `dmPolicy: allowlist` | отвечает только на ваш ID |
| `groupPolicy: disabled` | не работает в группах |
| `exec: allowlist + ask` | перед неразрешённой командой на сервере спрашивает вас в Telegram кнопкой |
| `fs.workspaceOnly` | работает с файлами только в своей папке |
| `elevated: off` | без root-прав |
| `heartbeat: 2h, 08–23` | самопроверка раз в 2 часа и не ночью (экономит деньги) |

Всё это — в `xavfsiz-sozlama.json5`, с комментариями.

**Помните:**
- Не давайте Jarvis пароли и номера карт
- В письме или на сайте может быть спрятана команда «сделай это» (prompt injection). Jarvis не должен её
  выполнять — но 100% гарантии нет. Поэтому важные действия — только с вашим подтверждением
- Не запускайте один токен бота в двух местах

## Проблемы

| Симптом | Причина и решение |
|---|---|
| Бот вообще не отвечает | `openclaw status` → работает ли gateway. `openclaw logs --follow` → читайте ошибку |
| Ответ приходит через несколько минут | сервер медленно подключается к Telegram. `bash check.sh <TOKEN>` → смотрите ❌ и 👉 |
| `check.sh`: «IPv4 orqali Telegram'ga ulanib bo'lmadi» | хостинг блокирует Telegram. Отправьте в поддержку результат `mtr -rwc 20 -T -P 443 149.154.167.220` или смените регион/провайдера |
| «Eski webhook qolgan» (остался старый webhook) | `curl "https://api.telegram.org/bot<TOKEN>/deleteWebhook?drop_pending_updates=true"` |
| Бот не отвечает другому человеку | так и задумано. Добавить человека: `openclaw config set channels.telegram.allowFrom '[ID1, ID2]'` |
| `openclaw: command not found` | закройте и откройте терминал или `source ~/.bashrc` |

Дополнительно: `openclaw doctor --fix` — многие проблемы исправляет сам.
